# Yemen NewsGuard AI

منصة عربية مفتوحة المصدر للتحقق المساند من الأخبار والادعاءات في السياق اليمني، مع طبقة جديدة لرصد **انتشار الخبر** عبر الويب العام والمنصات الاجتماعية المفهرسة.

## ما الذي أضيف؟

### 1) لوحة رصد استخباراتية
شغّل `monitor_app.py` بدلاً من `app.py` للحصول على واجهة مخصصة:

- إدخال خبر/ادعاء واحد.
- توليد عبارات بحث متعددة، بما فيها عبارات دقيقة من النص عند توفر OpenAI.
- البحث عبر Tavily عند توفر المفتاح، إضافة إلى Google News وBing News وRSS وصفحات المصادر اليمنية المهيأة.
- إزالة تكرار الروابط.
- تصنيف النتائج إلى: موقع ويب، Facebook، X/Twitter، YouTube، Telegram، TikTok، Instagram عندما يظهر النطاق في الرابط.
- استخراج الحساب/الصفحة من روابط Facebook وX وTelegram العامة عندما تكون ظاهرة في الرابط.
- ترتيب النتائج بدرجة تطابق نصي، مع التفريق بين «تطابق قوي» و«تطابق جزئي».
- عرض خريطة انتشار حسب المنصة والنطاق والحساب/الصفحة.
- تصدير CSV وJSON وHTML.

### 2) الرصد الدوري
الملف `data/monitor_queries.csv` يحتوي على عبارات الرصد اليومية. ويشغّل `.github/workflows/daily-monitor.yml` عملية الرصد يومياً ويضع تقرير JSON كـ GitHub Actions Artifact لمدة 30 يوماً.

يمكن أيضاً تشغيل العملية يدوياً من تبويب **Actions** في GitHub عبر workflow `Daily Yemen NewsGuard Monitor`.

## مفاتيح Secrets

في Streamlit Cloud أضف:

```toml
OPENAI_API_KEY = "..."
TAVILY_API_KEY = "..."
# اختياري
OPENAI_API_BASE = "https://api.openai.com/v1"
NEWSGUARD_SEARCH_MODEL = "gpt-4o-mini"
```

وفي GitHub أضف القيم نفسها كـ **Repository Secrets** إذا أردت تشغيل الرصد اليومي من Actions.

> لا تضع مفاتيح API داخل ملفات Python أو CSV أو GitHub commits.

## الدقة والمنهجية

المنصة لا تدّعي مسح «كل الإنترنت». النتائج تعتمد على المحتوى العام القابل للفهرسة وواجهات البحث وRSS والصفحات العامة المحددة. المحتوى الخاص، والمجموعات المغلقة، والمنشورات التي تتطلب تسجيل دخول، وبعض صفحات المنصات التي تمنع الفهرسة، قد لا تظهر.

درجة التطابق ليست احتمال صحة الخبر. لكي نعتبر النتيجة دليلاً قوياً على إعادة النشر يجب مراجعة النص، التاريخ، المصدر، الرابط، والسياق. النتيجة التي تشبه الموضوع فقط لا تُعرض كدليل قوي.

## التشغيل

```bash
pip install -r requirements.txt
streamlit run monitor_app.py
```

## البنية

- `app.py`: الواجهة الأصلية للتحقق متعدد الوسائط.
- `monitor_app.py`: لوحة رصد انتشار الأخبار.
- `src/web_search.py`: اكتشاف نتائج الويب وتحليل التطابق.
- `src/monitoring.py`: تنظيم الأدلة، تصنيف المنصات والحسابات، وإنشاء التقارير.
- `scripts/daily_monitor.py`: تشغيل الرصد الدوري.
- `.github/workflows/daily-monitor.yml`: الجدولة اليومية.
- `data/monitor_queries.csv`: عبارات الرصد.
- `data/sources.csv`: المصادر اليمنية المهيأة.
