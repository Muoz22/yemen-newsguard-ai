# Yemen NewsGuard AI

منصة عربية مفتوحة المصدر للتحقق المساند من الأخبار والادعاءات في السياق اليمني. تدعم النسخة الحالية **النصوص، الصور ولقطات الشاشة، الفيديو عبر لقطات ممثلة، وروابط ومنشورات Facebook العامة**.

## المزايا

- تحليل نصي محلي قابل للتفسير دون API.
- البحث عن الادعاء في Google News وBing News وواجهات RSS المتاحة.
- مقارنة النتائج مع صفحات المصادر اليمنية العامة المحددة في `data/sources.csv`، وإظهار عنوان الخبر والرابط والمصدر ودرجة التشابه.
- استخراج النص الظاهر في الصور وتحليل السياق البصري عند توفر `OPENAI_API_KEY`.
- استخراج ثلاث لقطات ممثلة من الفيديو وتحليلها بصرياً.
- جلب بيانات OpenGraph المتاحة من روابط Facebook العامة، مع إمكانية لصق نص المنشور يدوياً.
- مقارنة الأخبار النصية مع قاعدة البيانات المرجعية.
- واجهة عربية واحدة في Streamlit.

## التشغيل محلياً

```bash
git clone https://github.com/Muoz22/yemen-newsguard-ai.git
cd yemen-newsguard-ai
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

يتطلب تحليل الفيديو وجود `ffmpeg` في النظام. في Streamlit Community Cloud يقرأ النظام ملف `packages.txt` ويثبته تلقائياً.

## تفعيل تحليل الصور والفيديو والذكاء الاصطناعي

في Streamlit Cloud افتح **Settings → Secrets** وأضف:

```toml
OPENAI_API_KEY = "ضع-المفتاح-هنا"
NEWSGUARD_VISION_MODEL = "gpt-4o-mini"
```

يمكن استخدام نموذج متوافق مع OpenAI بتحديد `OPENAI_API_BASE` عند الحاجة. إذا لم يوجد المفتاح، يظل تحليل النص المحلي متاحاً، بينما يتطلب تحليل الصور والفيديو مفتاحاً لنموذج يدعم الرؤية.

## النشر على Streamlit Community Cloud

1. افتح [share.streamlit.io](https://share.streamlit.io).
2. اختر المستودع `Muoz22/yemen-newsguard-ai` والفرع `main`.
3. اختر الملف `app.py` ثم اضغط **Deploy**.
4. أضف الأسرار السابقة من إعدادات التطبيق.

## القيود المهمة

هذه أداة فرز وتحليل مساند وليست حكماً آلياً نهائياً. البحث لا يعني فحص كل الإنترنت؛ يعتمد على نتائج الفهارس العامة وRSS وصفحات المصادر المدرجة، ولا يستطيع الوصول إلى المحتوى غير المفهرس أو الخاص أو الذي يتطلب تسجيل دخول. لا يمكن قراءة منشورات Facebook الخاصة. تحليل الفيديو يعتمد على لقطات ممثلة ولا يثبت كل ثانية أو صحة الصوت. كما أن اكتشاف التلاعب يحتاج أدلة المصدر والبيانات الوصفية ومقارنة عكسية، ولا ينبغي إعادة نشر أي حكم دون مراجعة بشرية.

## البنية

- `app.py`: واجهة Streamlit متعددة الوسائط.
- `src/analyzer.py`: تحليل النص ومقارنة السجلات.
- `src/media.py`: تحويل الصور، استخراج لقطات الفيديو، قراءة بيانات Facebook العامة، وتحليل الرؤية.
- `data/news_dataset.csv`: السجلات المرجعية.
- `packages.txt`: حزم النظام اللازمة للفيديو.
